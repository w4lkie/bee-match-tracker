# Bee Match Tracker

A fan-made memory match tracker for Bee Swarm Simulator. Track rewards and discovered pairs in six game modes.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root).

Routes: `/small/`, `/med/`, `/night/`, `/extreme/`, `/winter/`, `/spirit/`.

All data is kept in localStorage in the visitor's browser. Item icons are original simplified SVG illustrations, not official game icons.
