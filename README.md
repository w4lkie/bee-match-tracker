# Bee Match Tracker

A fan-made memory match tracker for Bee Swarm Simulator. Track rewards and discovered pairs in six game modes.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root).

Routes: `/small/`, `/med/`, `/night/`, `/extreme/`, `/winter/`, `/spirit/`.

All data is kept in localStorage in the visitor's browser. Item icons are original simplified SVG illustrations, not official game icons.

## Wiki artwork and theme

The site uses a honey-yellow and field-green, wiki-inspired interface. It attempts to display item images using the Bee Swarm Simulator Wiki's Fandom file redirect links, and falls back to original simplified SVG illustrations if those image requests fail. Some wiki filenames or redirects may not resolve; they have not been individually verified. This is an independent fan tool, not an official BSS or Fandom project. Bee Swarm Simulator artwork belongs to its respective owners. Source: https://bee-swarm-simulator.fandom.com/wiki/Items
